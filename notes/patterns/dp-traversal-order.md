# DP 遍历方向 / DP Traversal Order

> **一句话 / TL;DR**：遍历方向不是背出来的，是由转移方程的依赖方向**推**出来的——计算 `dp[当前]` 时，等号右边引用的状态必须已经算好。

## 何时用 / When to use

写 DP 时的固定步骤：先写状态定义和转移方程，**最后**才定遍历方向。以下场景尤其要停下来推一遍：

- 区间 DP（`dp[i][j]` 依赖内部更短的区间）
- 转移方程里出现 `i + 1`、`j - 1` 这类「反常」依赖
- 滚动数组降维（一维背包），依赖的是「上一轮」的值

## 核心思想 / Core idea

判据只有一条：**算到某个状态时，它依赖的状态必须已经算过**。

把转移方程里的每个维度单独拆开看依赖方向：

- 该维度依赖**更小**的索引（如 `dp[i]` 依赖 `dp[i-1]`）→ **正序**遍历
- 该维度依赖**更大**的索引（如 `dp[i]` 依赖 `dp[i+1]`）→ **倒序**遍历

以 LC 5 为例：`dp[i][j] = dp[i+1][j-1]`。i 维依赖更大的索引 → i 倒序；j 维依赖更小的索引 → j 正序。两个维度各推各的，互不干扰。

## 模板代码 / Template

```python
# LC 5 最长回文子串：dp[i][j] 表示子串 s[i..j] 是否为回文
n = len(s)
dp = [[False] * n for _ in range(n)]
for i in range(n):
    dp[i][i] = True          # 长度 1 的子串都是回文

# dp[i][j] 依赖 dp[i+1][j-1]：
#   i 依赖更大的索引 → i 倒序
#   j 依赖更小的索引 → j 正序
for i in range(n - 1, -1, -1):
    for j in range(i + 1, n):
        if s[i] == s[j]:
            dp[i][j] = True if j - i == 1 else dp[i + 1][j - 1]
```

## 变体 / Variants

| 依赖形态 | 遍历方向 | 典型题 |
|---|---|---|
| `dp[i]` ← `dp[i-1]`, `dp[i-2]` | i 正序 | 70, 198, 1137 |
| `dp[i][j]` ← `dp[i+1][j-1]` | i 倒序，j 正序 | 5 |
| `dp[i][j]` ← `dp[i-1][j]`, `dp[i][j-1]`, `dp[i-1][j-1]` | i、j 双正序 | 1143 |
| `dp[j]` ← 上一轮的 `dp[j-w]`（01 背包降维） | j **倒序**，防止用到本轮新值 | 416 |
| `dp[j]` ← 本轮的 `dp[j-w]`（完全背包降维） | j 正序，就是要复用本轮新值 | 322 |

区间 DP 的另一种等价写法：按区间**长度从小到大**枚举。本质相同——保证算长区间时短区间已就绪，只是把「依赖方向」显式换成了「依赖长度」。

## 易错点 / Pitfalls

- **方向错了通常不报错**，而是默默读到未计算的初始值（如 `False`/`0`）或本轮刚覆盖的新值，结果错但程序照跑——所以要靠推导预防，不能靠报错发现。
- 滚动数组降维后方向可能**反转**：二维 01 背包 i、j 都正序，降成一维后 j 必须倒序。判据不变，只是「依赖上一轮的旧值」在一维里表现为「依赖尚未被本轮覆盖的位置」。
- 区间 DP 的内层起点要保证合法区间（如 LC 5 中 `j` 从 `i + 1` 起，只填上三角），且长度 2 的区间（`j - i == 1`）没有内部子区间，需要单独作为 base case。
